# Site archive

`expanded-2026-10-05/` is the expanded Leonida Desk site as it stood before it was reverted to the
first, simpler version on 7 October 2026: GTA VI section, games pages, reviews, videos, newsletter,
contact, privacy and affiliate pages, plus the ad, affiliate, newsletter and share components and the
analytics script. To bring it back, copy its `src/`, `public/` and `package.json` over `site/` and run
`npm install` in `site/`.
